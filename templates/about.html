О проекте

Что такое Lirisense?

Lirisense — это CS2 cheat loader, разработанный для образовательных целей. Проект представляет собой инжекторDLL-файлов в процесс Counter-Strike 2.

Как это работает?

1. Авторизация

Пользователь вводит логин и пароль. Лоудер проверяет данные через API сервера.

2. Поиск процесса

Loader ищет запущенный процесс CS2 и получает к нему доступ.

3. Скачивание DLL

DLL-файл загружается с Google Drive в защищённой среде.

4. Инжекция

Используется LoadLibrary или Manual Map для загрузки DLL в процесс.

5. Очистка

DLL-файл автоматически удаляется после инжекции.

Методы инжекции

LoadLibrary

Классический метод. Создаёт удалённый поток и вызывает LoadLibraryW. Простой и надёжный.

Стандартный

Manual Map

Продвинутый метод. Ручной маппинг PE-секций, обработка релокаций и импорт-таблиц. Сложнее для детекции.

Продвинутый

Безопасность

HWID привязка

Аккаунт привязан к аппаратному идентификатору вашего ПК

Анти-отладка

Автоматическое закрытие при обнаружении отладчиков (IDA, x64dbg, ProcessHacker)

Случайные имена

Окна получают случайные имена для маскировки

Автоочистка

DLL-файл удаляется сразу после инжекции

Технологии

Win32 API Инжекция процессов
